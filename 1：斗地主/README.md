### 斗地主 项目描述（人）

使用 python 接入三个 api，让三个 deepseek-v4.1-flash 模型斗地主并将整个过程展示出来。

规则：传统斗地主规则，允许四带二（即四张相同点数的牌带两张单牌或两个对子，不允许同时带一张单牌和一个对子）。

我需要你用 python 实现三个模块（下面的“用户”表示运行这个 python 并观看的人类，“玩家”表示正在参与斗地主游戏的 AI agent）：

三个玩家名字分别是 Alice、Bob 和 Corleone。

- 显示（display）：主要是向用户展示出三个人手里的牌。3 作为最小牌放在最左侧，2 和小王大王作为最大牌放在右侧，中间按牌面大小（非点数大小）递进排列。花色在斗地主中的作用不大，可以忽略。大概的显示方案例如："3 | 4 4 | 5 5 5 | A A | 2 | X Y"（X 表示小王 Y 表示大王，这个是 python 的输出格式，也是 AI agent 看到的格式）。每个回合首先，写清楚第几轮的第几个玩家，然后把玩家名称写上，然后写" -> {下一个玩家名称} -> {下一个玩家名称}"，然后把三个玩家按照 Alice、Bob 和 Corleone 的顺序输出，把三个人手里的牌打印出来：Alice: ...

然后等这一轮回合对应玩家打出牌之后，将这个玩家的名字写上，然后" 打出 {牌面组合}"。

然后会有一个裁判器判定这轮是否合法。这个之后会介绍（来自 judge 模块）。

- 裁判（judge）：负责判定规则，即判断 AI agent 打出的牌面是否合法。实现一个判定函数，传入的参数是当前玩家和当前打出的牌面组合，和上一轮的牌面组合（如果上一轮为空则空），判断当前打出来的能不能接上上一轮的。

如果当前打出的牌面组合不合法，根据实际情况反馈（不合法牌面组合；已有牌库没有对应的牌；牌面组合小于上一轮牌面组合），抛出异常。

- BOT（bot）：调用 api，system prompt 里面说明清楚游戏规则，允许的 action 有两个，名称是"play"和"pass"，格式是"play({牌面组合})"和"pass()"，前者表示打出某个牌面组合，后者表示 pass。我们允许 AI agent 说很多内容（因为我也想看到 ai 是怎么想的），但最后是单独一行一个动作“Action: play({牌面组合})”或者“Action: pass()”。

然后一个主函数，首先建立三个 Agent，然后，给三个地主三级抢地主的机会（不叫 / 叫 x1 / 叫 x2），依次进行，以及要说清楚三个 Agent 自己的身份和自己的牌面，然后，每轮只需要额外告诉当前的 Agent 整个牌桌上的历史信息即可（即不用重复当前 Agent 手里的牌）。每一轮 Agent 操作之后，try 捕获异常，如果有问题让这个 Agent 重新操作（把异常信息给到当前 Agent，保存到整个历史记录里面），while 直到给出合法操作为止。

也即我们每次传给 AI agent 的是两个信息，一个是初始的牌的信息（包括自己的名字），一个是牌桌上的信息，叫完地主之后的三张地主牌也是放到牌桌上的信息，也即，AI agent 根据这些信息可以拼凑出自己的牌的信息，然后根据上一轮来打出当前轮的牌。

然后直到结束。每一轮的每个玩家打完之后 PAUSE 一下，需要我按回车键才能继续下一回合。
